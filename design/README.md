# Design files

`tokens.json` is the initial machine-readable visual foundation for Tailwind CSS. It is intentionally small and should grow only when a real component needs a reusable value.

The next design artifacts should be created from the product and architecture documents in this order:

1. App shell and navigation.
2. Typical study/testing page from [`STUDY-PAGE.md`](STUDY-PAGE.md).
3. Certification selection.
4. Answer feedback and results.
5. Progress and review views.

Design decisions should be reflected in `docs/DESIGN-SYSTEM.md` and, when architectural, in `docs/decisions/`.
