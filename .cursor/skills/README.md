# Project skills

These are project-local Cursor Agent skills. Each skill is a reusable workflow stored in a `SKILL.md` file.

- `add-certification` — create a new certification module and question-bank starter.
- `review-question-bank` — review existing study content for correctness, clarity, integrity, and accessibility.
- `build-study-feature` — take a learner-facing feature from a short brief to an implemented and verified change.

Keep skills focused. If a workflow becomes a project-wide invariant, move that guidance into `.cursor/rules/` instead.
