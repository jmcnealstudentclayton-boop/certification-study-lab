# Product vision

## Purpose

Certification Study Lab helps a learner turn an intimidating certification objective list into a repeatable study loop: learn a concept, practice retrieval, understand mistakes, and measure readiness.

## Primary user

An independent learner preparing for one or more professional certifications who wants a focused study tool that works locally, keeps data private, and explains answers instead of only reporting a score.

## Core loop

```text
Choose certification → choose study mode → answer → submit → understand feedback → review weak areas → repeat
```

## Initial study modes

- **Practice test:** a configurable set of questions with scoring and explanations.
- **Quick review:** a short session focused on a domain or weak area.
- **Question review:** inspect explanations and references without a test timer.
- **Progress:** see attempts, domain performance, and recent areas for review.

## Product boundaries

The first release does not need accounts, social features, live exam delivery, payments, or a server. The app should be useful offline after its static assets and content are available.

## Success signals

- A learner can begin a useful session in under a minute.
- Every wrong answer leads to actionable explanation or review guidance.
- The learner can see which domains need attention without interpreting raw statistics.
- Adding a new certification does not require rewriting quiz UI.
- The content remains clearly unofficial and ethically authored.
